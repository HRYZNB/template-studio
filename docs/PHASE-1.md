# 第一阶段完成范围：模板信息与草稿管理

第一阶段只建立可靠的单体零部件模板输入，不创建几何，不绑定材料，也不运行 AI。

## 已实现功能

1. 模板草稿新建、打开、搜索和切换；
2. 唯一模板编码、名称、用途、设计意图、制造类别、初始主体形态、负责人、组织、标签、单位制和坐标系；
3. 实例图片、图纸、规格和 STEP 等参考文件上传；
4. 文件格式、20 MB 大小限制、安全文件名和 SHA-256 内容寻址；
5. 图片预览、文件打开、从草稿移除以及审计证据保留；
6. 乐观并发保护，防止旧修订覆盖新修订；
7. 每次保存、上传、移除、完成和恢复都创建不可覆盖修订；
8. 草稿复制、软归档和恢复；
9. 历史修订查看和“以历史内容创建新修订”；
10. 服务端阶段检查、完成状态和修改后自动失效；
11. 导出包含九个核心 JSON 文档及附件的 `.rwpart` 源包；
12. 后续六阶段在界面中锁定，不提供无效按钮。

## 第一阶段通过条件

- 编码格式合法且在未归档草稿中唯一；
- 名称不少于 3 个字符；
- 模板类型固定为单体零部件，并已选择制造来源与主工艺；
- 用途说明不少于 10 个字符；
- 设计意图不少于 20 个字符；
- 已指定负责人。

标签和参考资料属于建议项，不阻止阶段完成，但会保留黄色提醒。

## 明确不属于第一阶段

- 原材料引用与复制；
- 二维草图与约束；
- 制造特征和动态集合；
- 参数变型与拓扑域；
- B-Rep、STEP/GLB、语义拓扑；
- 准入发布与 AI 补丁。

这些能力必须在各自阶段完成后才解除导航锁定。
