# 用户操作指南

## 1. 创建模板草稿

打开工作台后，在“模板信息”中填写名称并选择基础制造形态。当前纵向切片支持：

- 带返回边开口型材；
- 板材毛坯；
- 矩形管型材。

这些是通用制造算子，不与“立柱”“横梁”等具体零件名称绑定。后续零件类型通过组合算子、约束和接口形成。

## 2. 绑定原材料

点击左侧“材料库”或右侧“更换或复制材料”：

- 选择“引用材料”：模板保存外部材料 ID；每次编译读取最新源记录，并报告是否漂移。
- 选择“复制到本平台”：保存完整不可变快照；源库更新不影响该模板。

材料牌号、标准、表面等属于材料记录；宽度、长度、截面、供料方式等属于毛坯和模板参数。两者不能混为同一对象。

## 3. 定义毛坯和截面

填写长度、宽度、深度、返回边和壁厚。界面保留值来源，当前材料厚度会在首次绑定时带入，但用户可将壁厚作为公开实例参数。

## 4. 定义动态特征集合

在“孔特征集合”中逐行添加、删除和修改孔：

- 每个孔使用稳定 ID，如 `H001`；
- X/Z 是局部坐标；
- 直径是独立参数；
- 孔数量不限于 2、4、6，也不改变模板协议。

编译前，系统检查孔是否越界、端部/侧边净距和孔间重叠。集合会被 Lowering 层展开为确定性的静态算子列表，再交给 CAD Worker。因此动态孔数量不会要求几何图协议具有动态节点。

## 5. 保存、生成和校核

点击“生成并校核”：

1. 自动保存新的草稿修订；
2. 解析实际使用的材料快照；
3. 规范化参数并计算输入哈希；
4. 展开集合形成静态计划；
5. 独立 OpenCascade 进程生成 B-Rep；
6. 检查有效性、实体数量和体积；
7. 输出 STEP、STL 预览、静态计划、语义映射和诊断。

若有错误，诊断区会给出参数路径、错误代码和建议；几何失败不会被伪装成成功工件。

## 6. AI 辅助

当前 UI 已保留受控补丁入口，但默认不连接模型服务。后续接入时，AI 只能提出参数、集合、约束、接口等补丁，不能直接操作 B-Rep、覆盖草稿或发布版本。补丁必须经过能力检查、沙箱编译、差异比较和用户确认。

## 当前边界

本版本是可运行的第一条纵向切片，不等同于全部生产能力。尚需按路线继续实现：完全约束草图、更多制造算子、拓扑域/变型矩阵、语义面解析、参数域自动采样、不可变发布、`.rwpart` 打包、GLB/DXF、AI 补丁服务和生产级任务队列。
